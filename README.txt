ПРОСМОТР
Распакуйте архив и откройте index.html в браузере.
Для полноценной проверки и публикации используйте статический веб-сервер.
Если установлен Python, в папке сайта можно выполнить:
python -m http.server 8000
Затем открыть http://localhost:8000

ПУБЛИКАЦИЯ
Разместите содержимое архива в корневой папке статического хостинга.
Сборка и установка зависимостей не требуются.
Для переноса на другой домен обновите абсолютные адреса в метаданных HTML, sitemap.xml и robots.txt.
